# Calculadora de Matrizes em C

## Descrição

Este projeto consiste em uma calculadora de matrizes desenvolvida na linguagem C. O programa permite que o usuário escolha a quantidade de matrizes, informe seus valores e realize operações matemáticas.

## Funcionalidades

- Escolher a quantidade de matrizes;
- Informar as dimensões e valores das matrizes;
- Realizar soma;
- Realizar subtração;
- Realizar multiplicação;
- Realizar divisão;
- Exibir a matriz resultado.

## Tecnologias utilizadas

- Linguagem C
- Git
- GitHub

## Operações

As operações matemáticas são realizadas elemento por elemento entre as matrizes.

## Limitações

O programa permite trabalhar com até 10 matrizes, cada uma com no máximo 10 linhas e 10 colunas.
